# Лабораторная работа №2 - Мини-оболочка с файловыми командами

## Описание
Этот проект представляет собой мини-оболочку на Python, которая позволяет работать с файловой системой, имитируя базовые команды Linux. Все команды реализованы через стандартные библиотеки Python (os, shutil, logging, zipfile, tarfile, re). Все успешные команды и ошибки логируются в файл shell.log. Обработка ошибок осуществляется через собственные исключения.
## Доступные команды
- `ls` [-l] [path] - список файлов и каталогов в текущем каталоге (опция -l для подробного вывода)
- `cd` [path] - переход в указанный каталог
- `cat` path - вывод содержимого указанного файла
- `cp` [-r] path dir - копирование файла/каталога в указанный каталог (опция -r для рекурсивного копирования)
- `mv` path dir - перемещение файла/каталога в указанный каталог, переименование файла/каталога
- `rm` [-r] path - удаление указанного файла/каталога (опция -r для рекурсивного удаления)
- `zip` dir name - создание ZIP-архива
- `uzip` name - распаковка ZIP-архива
- `tar` dir name - создание TAR.GZ-архива
- `untar` dir - распаковка TAR.GZ-архива
- `grep` [-r] [-i] pattern path - поиск строк, соответсвующих шаблону, в файлах (опции -r для рекурсивного поиска, -i для поиска без учета регистра)
- `exit` - выход из терминала
## Запуск программы
Запуск программы осуществляется при помощи команды в терминале
```python
python -m src.main
```
